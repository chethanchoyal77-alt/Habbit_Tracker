# Habit Tracker

A simple and responsive **Habit Tracker Web Application** developed as an internship project. This application helps users create, manage, and track their daily habits to improve consistency and productivity.

## 📌 Features

- User Registration and Login
- Create New Habits
- Edit Existing Habits
- Delete Habits
- Mark Habits as Completed
- Track Daily Progress
- Responsive User Interface
- Secure User Authentication
- Data Storage using MySQL

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP (Apache Server)

## 🚀 Installation

1. Clone the repository

```
git clone https://github.com/your-username/Habit_Tracker.git
```

2. Move the project folder to the **htdocs** directory of XAMPP.

3. Start **Apache** and **MySQL** from the XAMPP Control Panel.

4. Open **phpMyAdmin**.

5. Create a new database named:

```
habit_tracker
```

6. Import the SQL file from the **database** folder.

7. Open your browser and visit:

```
http://localhost/Habit_Tracker/
```
